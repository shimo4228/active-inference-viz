### 重要な判断
- **PyTorch autograd → 解析的 Jacobian**: 3関節平面アームの FK Jacobian は閉形式 2×3 行列。dynamics 関数の勾配も定数 (-λI or 0)。数値微分との一致を確認済み
- **簡略化ボディモデル**: Pymunk 物理エンジンなし。actions を直接 joint angles に適用。active inference の数学を理解するには十分
- **editable install**: `uv pip install -e .` + hatchling でパッケージ認識。pytest の pythonpath と両方設定
